# Ролі та права доступу

Використовуйте цей файл, коли питають «чи можу я…», «чому я не бачу…», «хто може…».

## Ролі

| Роль | Хто це | Домашня сторінка |
| --- | --- | --- |
| Власник | Власник бізнесу, останнє слово в усіх рішеннях | Огляд |
| Менеджер | Щоденна робота всіх служб, без питань власності та безпеки | Огляд |
| Рецепція | Заїзди, виїзди, гості, рахунки гостей | Огляд |
| Прибирання | Прибирання номерів | Прибирання |
| Продажі / Маркетинг | Запити, пропозиції, доступність, аналітика каналів | Продажі |
| Бухгалтер | Оплати, звірка, документи | Оплати |
| Технічне обслуговування | Ремонти й технічний стан номерів | Номери |

Одна людина в малому готелі може виконувати кілька ролей. У демо роль обирають на екрані «Тестовий вхід».

## Відкрити розділ не означає мати право на всі дії в ньому

| Дані або дія | Хто може |
| --- | --- |
| Бачити рахунок гостя, передоплату, залишок | Власник, Менеджер, Рецепція, Бухгалтер |
| Загальні фінансові звіти та експорт готелю | Власник, Менеджер, Бухгалтер (Рецепція бачить лише оплати за зміну) |
| Аналітика продажів і каналів | Власник, Менеджер, Продажі (без боргів гостей і повернень) |
| Прийняти оплату | Власник, Менеджер, Рецепція, Бухгалтер |
| Повернення коштів або виправлення бронювання платежу | Власник, Менеджер, Бухгалтер. Рецепція може лише «Запросити погодження» |
| Змінювати бронювання | Власник, Менеджер, Рецепція |
| Змінювати ціни, типи номерів, додавати номери | Власник, Менеджер |
| Заблокувати номер | Власник, Менеджер. Інші можуть повідомити про проблему й запросити блокування |
| Призначати прибирання | Власник, Менеджер |
| Експорт, об'єднання, видалення гостей | Власник, Менеджер |
| Керувати працівниками | Власник (усіма); Менеджер (лише операційним персоналом, не може надати роль Менеджера) |
| Власність, безпека, деактивація готелю | Лише Власник. Останнього Власника видалити не можна |

Прибирання й технічне обслуговування за замовчуванням не бачать імен гостей, контактів і цін. Продажі не бачать платежів гостей.

## AI-помічник усередині Hotel OS
AI-помічник працює в межах ролі: не показує в чаті, підказках та історії дані, недоступні цій ролі. Наприклад, прибиральниці він не розповість про борги гостей, а відділу продажів не покаже деталі ремонтів (але про вільні номери відповість).

## Якщо дії немає
Якщо потрібна дія недоступна ролі, користувачу слід звернутися до Власника або Менеджера. Для повернень і блокування номерів у системі є кнопки запиту погодження.
